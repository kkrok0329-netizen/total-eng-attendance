# 배포 준비 검증 결과

검증일: 2026-11-05 (한국 시간)

## 자동 검사

- `npm run check`: 서버·프런트엔드·서비스워커 JavaScript 구문 검사.
- `npm test`: 12개 서버 통합 테스트 통과.
- 테스트는 매번 별도의 임시 DB 또는 메모리 DB를 사용하며 가상 정보만 입력합니다.

검증 항목: 회사 코드 없는 가입·동의·안내 설정·생년월일 6자리와 비밀번호 4자리, 중복 가입, 사용자별 조회 권한, 관리자 인증과 만료·종료, 잘못된 요청과 CSRF 차단, 인증 실패 제한, 소수 공수·일당 계산, 과거 일당 유지, 다른 로그인 세션에서 조회, 삭제, 신상·작업내용 암호화, 백업과 재시작, 잘못된 암호화 키 감지, 동일 생년월일 계정 구분과 동시 중복 가입 차단, 기존 DB 로그인 전환, 8자리 관리자 비밀번호, PWA manifest·아이콘·오프라인 문서.

## 브라우저 동작 확인

임시 로컬 서버와 가상 작업자 계정으로 확인했습니다. 실제 운영 비밀번호나 실제 개인정보는 사용하지 않았습니다.

- 가입 → 일당 180,000원 설정 → 공수달력 진입.
- v1.1.0 가입 화면에서 회사 코드 입력란이 없는 것 확인. 생년월일 6자리와 앞자리가 0인 비밀번호 4자리로 가입 → 로그아웃 → 같은 정보로 재로그인 성공 확인.
- 0.25공수, 현장, 작업내용 입력 → 저장 → 달력 복귀 → 45,000원 및 4.5만원 표시.
- 설정 → 관리자 비밀번호 인증 → 등록 작업자 목록.
- 작업자 상세에서 목록 보기 → 달력 보기 → 날짜 선택 → 해당 날짜 작업내용 표시.
- 320px 브라우저 폭에서 관리자 달력과 공수 입력 화면의 가로 넘침 없음. 입력 글씨 18px, 공수 선택 버튼 높이 76px 확인.

확인 중 발견한 저장 후 화면 전환 오류와 달력 금액의 만원 단위 반올림 오류는 수정 후 같은 브라우저 흐름으로 재확인했습니다.

## 아직 확인하지 않은 것

- Docker가 이 PC에 없어 컨테이너 빌드와 Caddy 인증서 발급은 실행하지 않았습니다.
- 외부 호스팅, 도메인과 실제 배포 URL은 아직 없습니다.
- 실제 갤럭시·아이폰 기기에서 홈 화면 설치와 Safari/삼성 인터넷 동작은 HTTPS 배포 후 확인해야 합니다. 브라우저 화면 폭 검증이 실기기 검증을 대신하지 않습니다.
- 개인정보 안내와 주민등록번호 수집 설정은 회사 담당자가 실제 기준으로 설정해야 합니다.
