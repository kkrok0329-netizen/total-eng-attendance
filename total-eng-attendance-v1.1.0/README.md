# TOTAL ENG 근태 관리

갤럭시와 아이폰에서 같은 HTTPS 링크로 접속하고 홈 화면에 추가하는 PWA입니다. ChatGPT 계정은 필요하지 않습니다.

## 기능

- 회사 코드 없이 최초 가입: 이름, 생년월일 6자리, 전화번호, 은행, 계좌번호, 숫자 4자리 비밀번호.
- 주민등록번호 입력은 `COLLECT_RRN=true`와 수집 근거가 설정된 경우에만 표시됩니다. 기본값은 비활성화입니다.
- 생년월일 6자리와 비밀번호 4자리로 다른 휴대폰에서도 같은 기록 조회. 생년월일이 같아도 다른 비밀번호로 가입할 수 있으며 동일한 조합은 중복 가입을 차단합니다.
- 일당 설정, 공수 0.25/0.5/0.75/1/1.5/휴무 선택, 소수점 둘째 자리까지 직접 입력.
- 날짜별 현장·작업내용 입력, 수정, 삭제. 기존 기록의 적용 일당 유지.
- 설정 → 관리자 인증 → 작업자 선택 → 달력/목록 전환. 관리자 인증은 20분 유지.
- 관리자만 전체 주민번호·계좌를 1분간 표시하며 조회 이력을 서버에 기록.
- 인터넷이 끊기면 저장하지 않고 연결 안내. 개인정보와 API 응답을 서비스워커에 저장하지 않음.

## 로컬 실행

Node.js 24.16 이상 24.x가 필요합니다. 외부 npm 패키지 설치는 필요하지 않습니다.

```powershell
npm run setup
```

생성된 `.env`에서 `PRIVACY_NOTICE`에 회사의 실제 개인정보 안내를 설정하세요. `ADMIN_PASSWORD`는 관리자 인증에 사용합니다. 회사 등록코드는 사용하지 않습니다. 값을 Git이나 배포 ZIP에 포함하지 마세요. 그런 다음:

```powershell
npm start
```

브라우저에서 `http://127.0.0.1:3000`을 여세요. 처음에는 작업자가 없으므로 직접 가입해서 확인합니다. 로컬 HTTP는 개발용이며 휴대폰 배포는 HTTPS가 필요합니다.

## 배포 및 백업

[DEPLOY.md](DEPLOY.md)를 참고하세요. 서버 한 대에 Docker Compose로 실행하는 구성입니다. 데이터베이스는 서버의 영구 볼륨에 저장되며 여러 서버에 같은 SQLite 파일을 공유하는 구성은 지원하지 않습니다.

GitHub 업로드와 관리형 서버 연결 방법은 [GITHUB_UPLOAD_GUIDE.txt](GITHUB_UPLOAD_GUIDE.txt)에 있습니다. `render.yaml`은 유료 서버와 영구 디스크의 배포 설정이며, 실제 서비스 생성과 결제는 사용자가 Render에서 진행합니다. 서버가 발급한 HTTPS 주소로 설치 링크를 공유할 수 있습니다.

등록 신상·작업내용은 AES-256-GCM으로 암호화합니다. 비밀번호는 scrypt 해시로 보관하며, 서버가 모든 조회 권한을 검사합니다. 기본 비밀번호 `1234`나 가상 작업자 데이터는 포함하지 않았습니다.

스프레드시트 자동 연동은 이 버전에 포함하지 않았습니다. 현재 기준 데이터는 서버 DB이며 관리자 화면에서 조회합니다. 실제 배포 URL, 호스팅 계정, 도메인, 회사 개인정보 안내와 운영 기준 설정이 남아 있습니다.

## v1.1.0 로그인 변경

기존 DB와 기록은 삭제하지 않고 로그인용 인덱스를 추가합니다. 이전 버전에서 로그인된 계정은 새로고침하면 생년월일과 4자리 비밀번호를 설정하는 화면으로 안내됩니다. 새 정보를 저장한 뒤부터 변경된 방식으로 로그인합니다. 이전 계정의 로그인 세션이 없는 경우에는 먼저 관리자와 계정 전환 방법을 확인하세요.
